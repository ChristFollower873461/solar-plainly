# Brand

## Name

Solar Plainly

Descriptor: Open-source solar contract check and system record.

Tagline: Understand the deal. Keep the system.

The name communicates plain language and solar ownership without implying affiliation with OpenSolar or using the crowded Honest Solar name.

## Mark

The mark combines a document, rising sun, and small solar-panel grid. It is intentionally about records and clarity rather than installation sales.

Files:

- `docs/images/solar-plainly-icon-source.png`: generated source raster.
- `public/icon-512.png`: standard PWA icon.
- `public/icon-512-maskable.png`: maskable PWA icon.
- `public/icon-192.png`: small PWA icon.
- `public/favicon.png`: browser icon.

## Generation Record

The source raster was created with OpenAI's built-in image generation tool on 2026-08-09 using this production prompt:

```text
Use case: logo-brand
Asset type: square PWA and GitHub repository icon for an open-source homeowner solar contract and system-care app named Solar Plainly
Primary request: Create a memorable, simple icon with no text: an open paper document whose folded top corner becomes a small rising sun, with one crisp solar-panel grid line near the bottom. The mark should communicate clarity, records, and solar ownership rather than installation sales.
Style/medium: precise flat editorial vector-like illustration rendered as a polished raster icon, strong silhouette, minimal geometry, no photorealism
Composition/framing: centered symbol, square 1:1 canvas, generous safe padding, readable at 32px
Color palette: deep fern green, bright white, charcoal ink, and one restrained warm yellow sun accent; no blue-purple gradient
Lighting/mood: flat, calm, trustworthy, candid
Constraints: no words, no letters, no watermark, no mockup device, no rounded-square app-icon container drawn inside the image, no gradients, no shadows, no roof or house silhouette, no hands, no people
Avoid: generic sustainability leaf, stock solar installer logo, glossy 3D, beige-dominated palette
```

## Interface Tokens

- Fern green `#0b7443`: primary actions and active states.
- Ink `#19211d`: primary text.
- Canvas `#f6f8f6`: page background.
- White `#ffffff`: working surfaces.
- Yellow `#f4c542`: terms needing an answer.
- Blue `#276b93`: informational review items.
- Red `#ad3f32`: destructive actions and errors.

The interface uses restrained 5-7 pixel radii, thin borders, no decorative gradients, and compact system typography.
