# Privacy

Effective date: 2026-08-09

Solar Plainly is designed to work without an account or application server.

## Data the App Handles

The user may choose to enter or import:

- solar agreements and extracted text;
- system and equipment details;
- warranty, permit, inspection, utility, and manual files;
- monthly production totals;
- maintenance tasks and service notes.

## Where Data Is Stored

The working record is stored in IndexedDB inside the current browser profile. PDF extraction and contract rules run on the user's device.

The project does not operate analytics, advertising, lead-sale, account, document-upload, or AI-processing endpoints.

External resources are contacted only after the user opens an external link. Hosting providers may receive ordinary web request information when the static application files are loaded.

## User Controls

The user can:

- export the complete record as JSON;
- import a compatible backup;
- erase the local record from the Settings screen;
- clear site data using browser controls.

Downloaded backups are outside browser control. The user should protect or delete them using normal device security tools.

## Contact

Use the repository issue tracker for non-sensitive privacy questions. Use the private vulnerability-reporting path in [SECURITY.md](SECURITY.md) for sensitive reports.
